# Inkfluently — Naming & Brand Design Brief

**Name decided: Inkfluently** (rebranded from the prototype's working name, "Daily Dictée"; refined from the earlier shortlist pick "Inkfluent"). **Domain: inkfluently.com** (no hyphen — chosen deliberately over the hyphenated `ink-fluently.com` for cleaner word-of-mouth, typing accuracy, and brand-surface legibility, especially given the child-facing audience). Ink + "write fluently" — directly encodes the confirmed fluency-first positioning (§5), and sits in the same adjective+"-ly" naming family as Grammarly (another writing-assessment tool), which gives it a familiar, relevant association. Trademark availability still to be checked by the user before fully committing.

Reference brief for the rebrand: name, visual identity, and copy tone across the rebuild.

## 1. Name

- **Decided: Inkfluently.** Domain secured: `inkfluently.com`.
- Shortlisted first as "Inkfluent" (shorter, cleaner noun-shape), then refined to "Inkfluently" for its direct "write fluently" hook and the Grammarly-family precedent — chosen over brevity.
- (Note: Bhanzu was referenced by the user for its **sign-up/account model** — a main-account-holder + user split, self-registration at 18 — not for naming style. See the account-model note in the product spec, §5a, for the precise terminology: "main account holder" and "user," not "parent"/"child".)
- **Answer: Inkfluently.** Full candidate list kept in §7 below for reference / backup options.

## 2. Who's the buyer, who's the user

- **Buyer**: parents, on a **yearly subscription**.
- **User**: children of any age, but the product is **primarily built for children up to roughly 18–20**. No hard age gate — **over-18s can be the direct user/subscriber themselves**, not only a parent buying on a child's behalf.
- **Geography**: **global product, no age or region restriction** built into the design.

## 3. Personality & tone

- **Not distracting, but fun and playful.** The practice screen itself should stay focused (it's a 10–15 minute daily task, not a game to get lost in), while the surrounding brand voice, name, and non-practice screens (home, streaks, dashboard) can carry real personality and warmth.

## 4. Visual identity

- **Keep the paper/ink metaphor — confirmed, not up for debate.** The notebook-rule textures, ink accent colors, and handwriting-adjacent type pairing (Fraunces + IBM Plex) carry forward into the rebrand.

## 5. Positioning

- **Primary: handwriting fluency** (legibility + writing speed/pace — the WPM and legibility metrics).
- **Secondary: accuracy** — transcription correctness against the dictated passage is still analyzed and shown, but framed as a secondary metric, not the headline value. This is a shift from the prototype, which currently presents legibility and accuracy as two equal, side-by-side scores — the rebuild's UI hierarchy (and the AI-review prompt's framing) should visually and verbally lead with fluency, with accuracy available but de-emphasized.

## 6. Practical constraints

- Not yet discussed in detail (domain TLD preference, trademark screening) — the user is checking domain availability directly against the name candidates below.

## 7. Name candidates (15)

Style target: short, coined or lightly-blended words (à la Bhanzu), easy to pronounce globally, evoking pen/ink/handwriting/fluency rather than literally describing the product. **Not yet checked for domain or trademark availability — check both before committing, since a catchy invented word can still collide with an existing registered mark even if the exact domain looks free.**

| # | Name | Root idea |
|---|------|-----------|
| 1 | **Inkfluent** | ink + fluent — directly names the fluency positioning |
| 2 | **Quillo** | quill (writing instrument) + playful "-o" |
| 3 | **Scribbly** | scribble, warm and kid-friendly |
| 4 | **Handzu** | hand(writing) + Bhanzu-style "-zu" suffix |
| 5 | **Fluenta** | fluency, global/Latinate sound |
| 6 | **Penloop** | pen + the loops of cursive handwriting |
| 7 | **Writezu** | write + "-zu" suffix, same family as Handzu |
| 8 | **Scriptzu** | script + "-zu" suffix |
| 9 | **Loopink** | the loop of a pen stroke + ink |
| 10 | **Wrivo** | write, shortened + punchy "-vo" ending |
| 11 | **Pennly** | pen + friendly "-ly" ending |
| 12 | **Scrawlio** | scrawl (handwriting, affectionately) + "-io" |
| 13 | **Inkly** | ink, shortened and softened |
| 14 | **Scribeo** | scribe + "-o" |
| 15 | **Fluentink** | fluent + ink, inverse pairing of #1 |

A few lean harder into **fluency** (Inkfluent, Fluenta, Fluentink) matching the confirmed primary positioning; others lean into the **pen/ink/paper** visual metaphor (Quillo, Penloop, Loopink, Inkly, Scribbly, Scrawlio); a few are shorter coined blends (Handzu, Writezu, Scriptzu, Wrivo, Pennly, Scribeo) chosen purely for recall and playfulness, not because of any specific reference brand.
